- **Artistree_Project_Presentation.pdf**: 같은 내용과 레이아웃의 확인·배포용 PDF입니다.
- **발표_스크립트.md**: 장별 발표 멘트, 짧은 시연 순서, 예상 질문 답변입니다. PPT 발표자 노트에도 멘트를 넣었습니다.

- **validation.json**: 장수·발표자 노트·도형 범위·텍스트 폭 검사 결과입니다.

## 열기 / 수정

- PowerPoint 또는 Keynote에서 PPTX를 열어 발표자 이름 등을 추가하면 됩니다.
- 한글은 `Apple SD Gothic Neo`, 영문은 `Helvetica Neue`를 지정했습니다. Mac에서 사용하기 좋은 구성입니다. 다른 환경에서 글꼴이 바뀌면 `맑은 고딕` 등 사용 가능한 한글 글꼴로 바꾸거나 PDF로 확인하세요.
- 실제 화면은 정적 캡처입니다. PPT 안에서 음악이 자동 재생되지는 않습니다.
- 라이브 시연은 앱 서버를 실행한 뒤 `http://127.0.0.1:3000/`에서 진행하세요. 외부 서비스가 느리거나 재생을 제한하면 캡처 화면으로 대체할 수 있습니다.
- 대외 공개·배포 전 화면 속 사진과 영상 제공처의 권리·표시 조건을 확인하세요.

## 재생성 (선택)

기존 앱의 개발 의존성과 분리한 Python 환경에서 실행합니다.

```sh
python -m pip install python-pptx Pillow reportlab
python presentation/build_deck.py
```

PDF 생성에는 한글 지원 TTF 글꼴이 필요합니다. 기본 경로가 없는 환경에서는 `ARTISTREE_PDF_FONT` 환경 변수로 지정하세요. 앱 소스나 실행 설정은 수정하지 않습니다.
